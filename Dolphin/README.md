# Dolphin Companion

This folder is the companion pack for the real-device validation pass.

Use it to keep the iPhone-side runtime checks organized and adjacent to the project docs without mixing them into the portable core code.

## Included

- Runtime checklist
- Device validation notes
- Known runtime requirements for the live spoofing path

## Main rule

Do not treat the device runtime as a host build problem. It is a hardware requirement, not a library problem.
